# تمرین ۱ درس LLM Agents: چالش استدلال محلی با Ollama

## ۱. معرفی و معماری Agent
در این پروژه، یک Agent استدلال‌گر دو مرحله‌ای مبتنی بر مدل محلی `qwen3:8b` روی Ollama پیاده‌سازی شده است تا مسائل ریاضی، منطقی و ارضای قیود (CSP) را بدون نیاز به اینترنت حل کند:

1. **مرحله اول (Planner & Solver):** مسئله ورودی را تحلیل کرده، متغیرها، قوانین و قیود را استخراج می‌کند و با استدلال گام‌به‌گام (Chain-of-Thought) پاسخ اولیه را به دست می‌آورد.
2. **مرحله دوم (Verifier & Strict Formatter):** راه‌حل تولیدشده در مرحله اول را با تمام قیود صورت مسئله تطبیق می‌دهد تا در صورت وجود خطای محاسباتی یا منطقی آن را اصلاح کند و در نهایت، پاسخ خالص را دقیقاً مطابق فرمت خواسته شده در تگ `<FINAL_ANSWER>` استخراج می‌کند.
3. **پاکسازی و مدیریت خطا (Post-Processing & Fallback):** خروجی مدل از هرگونه تگ اضافی، علائم Markdown و پیشوندهای متنی پاکسازی می‌شود و در صورت بروز خطا در مرحله بازبینی، از پاسخ مرحله حل‌کننده به عنوان پشتیبان استفاده می‌گردد.

## ۲. پیش‌نیازها و نصب
ابتدا مطمئن شوید سرویس Ollama روی سیستم در حال اجراست و مدل پایه تمرین دریافت شده است:

    ollama pull qwen3:8b

سپس وابستگی‌های پایتون را نصب کنید:

    pip install -r requirements.txt

## ۳. نحوه اجرای برنامه
برنامه از رابط خط فرمان استاندارد تمرین پشتیبانی می‌کند (ورودی می‌تواند یک شیء JSON تکی یا لیستی از مسائل باشد):

    python main.py --input input.json --output output.json
